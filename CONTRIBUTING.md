## 🤝 Contributing

### Reporting Issues

- Search existing issues first.
- Use the issue templates if available.
- Provide clear reproduction steps.
- Include environment details.

### Suggesting Enhancements

- Check the existing discussions.
- Explain the use case and expected conduct.
- Consider the implementation complexity.

### Code Contributions

#### Prerequisites

- A Stellaris installation for verifying changes in game
- The [Universum Infinitum - Name Lists](https://github.com/hmlendea/stellaris-ui-name-lists) mod, which supplies the referenced name lists

#### Development Setup

```bash
# Clone the repository
git clone https://github.com/hmlendea/stellaris-ui-species-names.git
cd stellaris-ui-species-names

# Install dependencies
# No dependencies to install; the repository content is the mod itself.
```

#### Making Changes

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/your-feature-name`
3. Make your changes.
4. Commit with clear and descriptive messages.
5. Push to your fork.
6. Open a Pull Request.

#### Pull Request Guidelines

- Target the `master` branch.
- Keep PRs focused and atomic.
- Revise documentation if applicable.
- Include tests for any new functionality.
- Ensure the CI checks pass.

### Documentation

- Revise relevant docs for changes.
- Follow the documentation style guide.
- Preview changes locally if possible.
