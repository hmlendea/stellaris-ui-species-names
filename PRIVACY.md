## 🔎 What This Document Covers

This document describes how Universum Infinitum: Species Names at https://github.com/hmlendea/stellaris-ui-species-names handles personal data. It covers the application behaviour and verified integrations described below. Where the software is self-hosted, the instance operator may have separate responsibilities described below.

## 📥 Data We Handle

### Data Provided to the Application

- The mod does not request or accept personal data. It consists of static Stellaris name-list text files and mod descriptor files.

### Data Generated or Collected by the Application

- The repository contains no executable mod code that collects personal data or generates application telemetry, diagnostics, or access logs.

### Data Received from Integrations

- The mod has no integration code and receives no personal data from third parties.

## 🧭 Processing and Use

The application processes the data described above for these verified functions:
- Provide species-name definitions to Stellaris — static text files; no personal data is involved.
- No analytics, diagnostics, telemetry, or account processing is performed by the mod — no personal data is involved.

## 🗄️ Storage, Retention, and Deletion

The mod's repository files are static text and metadata, not personal data. When installed, the mod files are stored in the location chosen by the user or distribution platform. The mod does not define retention or deletion for records held by Stellaris or distribution platforms. Those services may hold account or download records under their own policies; their operators control storage, retention, and deletion of those records.

## 🔗 External Processing and Integrations

The mod has no built-in external data transfer or integrations. Distribution platforms and Stellaris are separate services; any data they process when users access those services is governed by their own policies, not by this mod.

| Service or integration | Purpose | Data involved | Configuration or documentation |
|-----------------------|---------|---------------|--------------------------------|
| None built into the mod | No external processing by the mod | None sent by the mod | Not applicable |

## 🛡️ Data Protection and Security

The mod contains no executable component that handles personal data and implements no personal-data security controls. Keep the game, device, and any distribution-platform account secure using the safeguards provided by their respective operators. This document does not promise absolute security.

## 🔄 Document Changes

Update this document when application data flows, storage, integrations, or deployment responsibilities change. The current version is published at [PRIVACY.md](PRIVACY.md).
