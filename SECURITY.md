# Security Policy

This project is a Stellaris mod consisting of static species-name text files and descriptor metadata. It contains no executable code, telemetry, analytics, or diagnostics. This policy covers vulnerability reporting for the mod repository and its distribution artefacts.

## 🚨 Reporting a Vulnerability

Please do not disclose suspected vulnerabilities publicly before maintainers have had an opportunity to validate and remediate them.

To report a vulnerability:
- [GitHub Security Advisories](https://github.com/hmlendea/stellaris-ui-species-names/security/advisories)
- Contact the maintainers directly

## 📌 Scope

The original maintainers are not responsible for changes, modifications, or security issues introduced by downstream forks.

The subsequent report categories are in scope for this repository:
- Malicious content injected into release artefacts
- Supply-chain compromise of distribution channels
- Repository metadata tampering

The subsequent categories are out of scope unless explicitly stated to the contrary:
- Stellaris game engine vulnerabilities
- Steam Workshop, Paradox Mods, or Nexus Mods platform vulnerabilities
- Issues in the required dependency mod (Universum Infinitum - Name Lists)
- User-modified or third-party repackaged versions

## 📢 Disclosure Policy

This project follows coordinated disclosure:
1. Vulnerabilities are investigated privately.
2. A remediation plan is prepared and validated.
3. Public disclosure is published after a fix, mitigation, or agreed risk decision is available.
4. Credit is attributed in accordance with reporter preference and project policy.
